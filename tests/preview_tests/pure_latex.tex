\section{Mathematics}
We can render block mathematics easily:
\begin{equation}
f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!} (x-a)^n
\end{equation}

Also, inline math like $a^2 + b^2 = c^2$ works as expected.
